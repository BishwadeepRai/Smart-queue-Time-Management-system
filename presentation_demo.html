02 · Project workflow

From call events to a next-call estimate

The Week 5 model uses an ordered window of recent calls to estimate the service-standard outcome for the following call.

STEP 01

Prepare the data

Sort events by time and derive calendar features from call start time.

STEP 02

Build sequences

Use 20 previous calls from the same operating date as each input sequence.

STEP 03

Train an LSTM

Learn temporal patterns to classify whether the next call met the standard.

STEP 04

Test in time order

Hold out the latest 20% of call records to evaluate future-period performance.

Leakage prevention: wait length was excluded because it directly determines the target in this simulated dataset. Call identifiers and post-call fields were also excluded.

Key takeaway

The selected LSTM did not beat the majority baseline.

It identified 12.93% of the calls that missed the standard (missed-standard recall). This shows why accuracy alone is not enough when classes are imbalanced.

The dataset is simulated; these results do not establish that the model is ready for a real call centre.
